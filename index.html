📖 How Scores Work
DK Scoring Each Hit, Run, and RBI = +1 DraftKings point. A Home Run scores all three at once = +3 pts minimum in a single swing.
Guru Score A predictive ranking number — NOT raw DK pts. Combines 7 factors into one score. Higher = stronger pick tonight. Use it to rank players against each other, not as a points prediction.

Typical range: 50–400. Most playable picks score 120–280. Under 100 = weak play. Over 280 = elite matchup tonight. The #1 pick usually scores 250–380 on a good slate.
7 Score Factors 1. Season rate stats (H+R+RBI per game × 50 — normalized so April = September)
2. Last 10 games DK pts ×3 (most important — hot players win)
3. Pitcher platoon split (how bad is this pitcher vs this batter type)
4. Head-to-head career history vs tonight's pitcher (10+ PA required)
5. Batting order position (leadoff = most plate appearances)
6. Home/Away OPS split
7. Park factor + weather (wind blowing out = HR boost; dome = neutral)
Confidence Grade Overall betting confidence — combines ALL factors:
A+ = Everything lines up. Strong bet.
A = Very good play.
B+ = Good value with upside.
B = Solid but not perfect.
C+ = Risky — use caution, size down.
C = Low confidence — probably skip.
Low confidence with high Guru Score = great matchup but not enough recent data to fully trust yet. Wait for lineup confirmation.
Matchup Grade ONLY measures how vulnerable tonight's pitcher is to this batter's handedness (Left or Right):
A+ = Pitcher gets destroyed by this batter type.
A = Strong edge for the batter.
B = Slight edge.
C = Neutral — no real advantage.
D = Pitcher dominates this batter type — avoid.
Best picks have A or A+ on both Confidence AND Matchup.
DK Line Guide Over 0.5 = safe floor, nearly any productive start.
Over 1.5 = needs real contribution, good for hot bats.
Over 2.5 = multiple contributions needed, elite matchups only.
Over 3.5 = boom or bust, only with strong HR upside.
Lineup Status ★ Confirmed = official lineup posted, batting order factored into score.
⚠ Pending = lineups not posted yet. Scores run without order multipliers. Always re-run after 3:30 PM ET to get confirmed lineups and final scores.
🚫 Injury Flags Cards show a red 🚫 IL badge if a player is on the injured list, or an orange ⚠ Day-to-Day badge if questionable. IL players should be skipped — they will not play. Day-to-day players are a risk — wait for lineup confirmation before betting.
Recent Games Sparkline The bar chart shows last 10 games DK pts per game. Left = oldest game · Right = most recent game. Rising bars = player is heating up. Falling bars = cooling off. Green = 4+ pts · Blue = 2-3 pts · Gray = 0-1 pts.
📐 Math Projection (v4) Each card now shows a mathematical HRR projection broken into components:
Proj PA = projected plate appearances tonight based on lineup spot (Leadoff ~4.6, Cleanup ~4.2, 9th ~3.8).
Adj AVG = season batting average adjusted for tonight's pitcher matchup and career head-to-head history.
Proj H = (PA − projected walks) × adjusted AVG.
Proj R = times on base × team scoring rate (adjusted for park).
Proj RBI = runners on base per PA × drive-in rate + solo HR contribution.
Total = projected H + R + RBI blended 60% math model / 40% recent form.
Use this number vs the DK line: if Total > line → lean Over. If Total < line → lean Under or skip.
